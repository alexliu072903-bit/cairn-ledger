# 机制与边界

## 从会话到记录

1. watcher 观察来源文件的元数据变化；文件静默后启动同一个处理器。
2. 本地解析器只取已结束轮次中的人类消息，排除子 Agent、分类器自身和 relay 运行目录等来源。
3. 规则粗筛去掉没有纠正信号的消息；候选与必要的前文交给 Codex CLI 分类。
4. 本地校验每个输出：原话必须来自输入，类别与规则引用必须有效，敏感内容检查通过后才入账。
5. `ledger.jsonl` 保存事件事实，`regressions.md` 从账本全量生成。原始消息的稳定 event id 用于去重。

普通内容编辑、补充事实、初始约束和不确定项不入账。它不会提出规则修改、自动改规则或替用户评价 Agent 表现。

## 覆盖范围

当前版本面向 macOS，Python 3.9+，仅依赖标准库。真实分类需要已登录的 Codex CLI，且支持 `ledger.py` 中使用的 `codex exec` 参数；CLI 或 transcript 格式升级可能需要适配。

| 覆盖 | 当前限制 |
| --- | --- |
| 本机 Claude Code transcript | 不保证云端会话落到本机，不采集 claude.ai |
| 本机 Codex transcript | 仅处理当前解析器支持的记录结构；不支持时显示错误 |
| 已结束轮次 | 不把静默当作会话已永久结束；未结束轮次暂缓 |
| 原文件与行号定位 | 原生会话深链兼容性尚未验证，不能保证点击后打开目标会话 |
| 方法纠正分类 | AI 判断仍可能误判或漏判，需核对摘录及原文 |

## 数据与模型

来源 transcript 不会被复制进源码仓库。运行配置、游标、日志、事实账本和阅读视图保存在用户选择的本机目录。

启用分类后，发送给模型服务的内容包括候选消息短片段、必要前文、规则文本和已有类别。常见密钥、邮箱和手机号会尝试脱敏；规则文本会原样发送，正则不能识别所有隐私或客户信息。分类默认关闭。

模型在独立 cwd 中运行，使用 ephemeral、只读 sandbox 和禁用工具设置。写入由本地代码完成，输出先经过校验。调用前预留额度；失败或结果未知的请求也占用额度。

`.gitignore` 是防误提交的一层保护。输出目录应始终位于源码仓库外，发布任何改动前仍需检查暂存区。
